## tasker4u-backup ##

## 1. En tu cuenta de GitHub crear un repositorio llamado tasker4u-backup
#2. En Configuración o Ajustes (abajo del todo) en Developer Settings, crea un Fine-grained token.
#3. Configúralo para No Expiration y en Repository Acces elige Only select repisotories y selecciona el tuyo de tasker4u-backup
#4. Por último, en la sección Permissions, dale a Add Permissions y busca y selecciona Contents. En la linea que se creará con nombre Contents, (a la derecha del todo) en Access donde dice Read-Only clica y selecciona Read and Write.
#5. Dale a Generate Token y cópialo para usarlo en la App.
